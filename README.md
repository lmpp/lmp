Local Lists — плагін власних списків для Lampa

Плагін для Lampa, що додає повноцінну підтримку власних колекцій та списків
фільмів і серіалів. Він органічно вбудовується в інтерфейс додатку, розділ
«Закладки» та вікно перегляду карток, а також підтримує хмарне резервне
копіювання та імпорт експортованих списків з Trakt.tv.

🌟 Основні можливості

  - Органічна інтеграція в «Закладки» («Вибране»):
      - Верхній лічильник: окрема кнопка-плашка «Мої списки» з відображенням
        загальної кількості створених списків.
      - Горизонтальний рядок «Мої списки»: розташований безпосередньо у списку
        закладок. Обкладинкою списку слугує постер першого доданого фільму з
        бейджем кількості елементів.
      - Швидка картка «+ Створити список»: зручна картка в кінці рядка списків
        для миттєвого створення нової колекції.
  - Керування колекціями:
      - Перегляд окремих списків у вигляді повнорозмірної сітки з постерами.
      - Видалення списку через кнопку меню або довге натискання (long press) на
        пульті чи мишці.
      - Видалення окремих фільмів зі списку через контекстне меню картки.
  - Додавання контенту прямо з картки фільму:
      - Інтеграція у вікно закладок фільму/серіалу (кнопка з прапорцем/закладкою
        на сторінці опису): натиснувши «Списки», відкривається перелік ваших
        списків із позначкою галочкою (✓), де вже присутній цей тайтл, або
        можливістю створити новий список на льоту.
  - Імпорт даних з Trakt.tv:
      - Підтримка офіційного ZIP-архіву експорту Trakt.tv.
      - Автоматичне розпакування та імпорт списків: користувацькі списки
        (lists-lists.json), Watchlist (lists-watchlist.json) та Favorites
        (lists-favorites.json).
      - Підтягування актуальних українських постерів і даних через TMDB API.
  - Резервне копіювання в хмару (опційно):
      - Збереження та відновлення бази списків у ваш персональний приватний
        GitHub Gist.
  - Повна багатомовність:
      - Підтримка інтерфейсу українською (uk), англійською (en) та російською
        (ru) мовами.

📦 Встановлення

1.  У Lampa відкрийте: Налаштування → Плагіни → Додати плагін.
2.  Вкажіть посилання на файл плагіна (або встановіть через локальне
    сховище/хостинг).
3.  Перезавантажте додаток або оновіть сторінку.
4.  Перейдіть у розділ «Закладки» («Вибране») — у списку з'явиться рядок і
    лічильник «Мої списки».

⚙️ Налаштування списків

Пункт «Налаштування списків» автоматично з'являється у головному меню
налаштувань Lampa. Тут доступні:

| Пункт                 | Опис                                                                                                     |
| :-------------------- | :------------------------------------------------------------------------------------------------------- |
| **GitHub Token**      | Вкажіть особистий токен GitHub (Personal Access Token) з дозволом `gist`. Значення маскується зірочками. |
| **Зберегти у хмару**  | Створює або оновлює приватний Gist `lampa_local_lists.json` із вашими актуальними списками.              |
| **Відновити з хмари** | Завантажує списки з вашого Gist і перезаписує локальні списки на пристрої.                               |
| **Імпорт з Trakt.tv** | Відкриває діалог вибору файлу для завантаження ZIP-архіву вашого експорту з Trakt.tv.                    |

📥 Як імпортувати списки з Trakt.tv

1.  У своєму акаунті Trakt.tv перейдіть у Settings → Account та запросіть
    експорт даних (Export data).
2.  Завантажте отриманий .zip-архів.
3.  У Lampa перейдіть у Налаштування → Налаштування списків → Імпорт з Trakt.tv.
4.  Оберіть завантажений ZIP-файл — плагін автоматично створить списки та
    завантажить постери й назви для знайдених фільмів і серіалів.

☁️ Як налаштувати синхронізацію через GitHub Gist

1.  Перейдіть на GitHub у Personal Access Tokens (Tokens classic).https://github.com/settings/tokens
2.  Створіть новий токен (Generate new token classic).
3.  У списку прав (scopes) позначте лише один пункт: gist (створення та
    редагування Gist).
4.  Скопіюйте отриманий токен (ghp_...).
5.  У Lampa відкрийте Налаштування списків → GitHub Token і вставте токен.
6.  Натисніть «Зберегти у хмару» для бекапу або «Відновити з хмари» на іншому
    пристрої для завантаження списків.

💡 Гарячі клавіші та взаємодія

  - Коротке натискання (Enter / OK / Клік):
      - По картці списку — перехід до перегляду вмісту списку.
      - По картці «+ Створити список» — виклик екранної клавіатури для введення
        назви.
  - Довге натискання (Long press / кнопка «Меню» на пульті):
      - По картці списку — меню вилучення списку.
      - По фільму всередині списку — меню видалення фільму з колекції.
