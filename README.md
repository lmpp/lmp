# Мої списки (Local Lists) — плагін для Lampa

Плагін додає власні іменовані списки фільмів і серіалів (окремо від стандартного «Вибране»), з хмарним резервним копіюванням через GitHub Gist та імпортом з Trakt.tv.

## Можливості

- **Власні списки** — створюйте будь-яку кількість іменованих списків (наприклад, «Подивитись з дружиною», «Улюблені трилери») і додавайте туди картки фільмів/серіалів прямо з картки контенту.
- **Інтеграція у сторінку «Вибране»** — списки відображаються як картки-папки прямо на стандартній сторінці закладок Lampa (клікабельні картки, включно з карткою «+ Створити список»).
- **Додавання/вилучення прямо зі стандартного меню «Вибране»** — кожен список з'являється окремим пунктом-чекбоксом просто в тому ж спливному меню, що й стандартні категорії закладок Lampa:
  - при довгому натисканні на картку в каталозі/пошуку (контекстне меню картки);
  - при натисканні кнопки «Закладки» на сторінці фільму/серіалу.
- **Приховування та впорядкування списків**
  - окремий екран «Редагувати списки» (Налаштування → Налаштування списків → Редагувати списки) дозволяє змінювати порядок списків і вмикати/вимикати їх видимість на сторінці «Вибране» без видалення самих списків.
- **Хмарний бекап через GitHub Gist**
  - Зберігає у приватний Gist як власні списки, так і стандартні закладки Lampa.
  - Потрібен персональний GitHub-токен.
- **Імпорт з Trakt.tv** — завантажте ZIP-експорт зі свого акаунту Trakt.tv, і плагін:
  - прочитає його прямо в браузері (JSZip підвантажується з CDN лише за потреби);
  - створить окремі списки для кожного вашого списку Trakt, а також для Watchlist і Favorites.
- **Налаштування вбудовані в загальні Settings Lampa** — окрема секція «Налаштування списків» з полем токена, кнопкою редагування списків, кнопками синхронізації/перезапису/відновлення та імпорту.

## Встановлення

1. У Lampa відкрийте **Налаштування → Розширення (плагіни)** і додайте посилання на файл https://lmpp.github.io/lmp/ll.js
3. Перезапустіть/оновіть Lampa — плагін ініціалізується автоматично після оновлення.

## Використання

### Додавання в список
Ваші списки тепер вбудовані прямо в стандартне меню закладок Lampa — окремого пункту «Списки» більше немає:
- **З каталогу/пошуку**: довге натискання на картку фільму/серіалу → у меню «Вибране»/«Закладки» кожен ваш список показаний як окремий чекбокс поруч зі стандартними категоріями.
- **Зі сторінки фільму**: кнопка «Закладки» → у списку, що з'явився, кожен ваш список так само показаний як чекбокс.

Позначте чи зніміть позначку з потрібного списку — зміни застосовуються одразу, без підтвердження. Картки, що входять хоча б до одного списку, додатково позначаються зірочкою.

### Перегляд списків
Перейдіть на сторінку **Вибране**: над стандартними розділами з'явиться пункт «Мої списки» з лічильником (веде до повного переліку), а трохи нижче — рядок карток-папок для швидкого доступу, включно з карткою «+ Створити список». Відкрийте список, щоб побачити всі елементи, або довгим натисканням на картку списку — видаліть список чи перейдіть до його редагування.

### Управління списками (порядок і видимість)
Налаштування → «Налаштування списків» → «Редагувати списки». На цьому екрані можна:
- перемістити список вгору/вниз кнопками стрілок — це впливає на порядок скрізь: у меню закладок, у рядку на сторінці «Вибране» тощо;
- увімкнути/вимкнути видимість списку — прихований список не показується на сторінці «Вибране» і в меню закладок, але дані в ньому зберігаються і беруть участь у синхронізації з хмарою.

### Резервне копіювання
1. Створіть [Personal Access Token](https://github.com/settings/tokens) на GitHub (достатньо прав `gist`).
2. Синхронізувати (Smart Merge): двостороннє об'єднання без втрати даних на обох сторонах (Локальне ⇄ Хмара).
3. Перезаписати в хмарі (Force Push): примусовий експорт — локальний стан на 100% затирає хмару (Локальне ➔ Хмара).
4. Відновити з хмари (Force Pull): примусовий імпорт — стан із хмари на 100% замінює локальні дані без злиття зі старими записами (Хмара ➔ Локальне).

### Імпорт з Trakt.tv
1. Експортуйте свої дані у [налаштуваннях Trakt.tv](https://trakt.tv/settings/data) (ZIP-архів).
2. Налаштування → «Налаштування списків» → «Імпорт з Trakt.tv» → оберіть завантажений ZIP.
3. Дочекайтеся завершення — списки, Watchlist і Favorites з'являться серед ваших локальних списків.

## Історія змін
