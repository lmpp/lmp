# Мої списки (Local Lists) — плагін для Lampa

Плагін для [Lampa], що додає власні іменовані списки фільмів і серіалів (окремо від стандартного «Вибране»), з хмарним резервним копіюванням через GitHub Gist та імпортом з Trakt.tv.

## Можливості

- **Власні списки** — створюйте будь-яку кількість іменованих списків (наприклад, «Подивитись з дружиною», «Улюблені трилери») і додавайте туди картки фільмів/серіалів прямо з картки контенту.
- **Інтеграція у сторінку «Вибране»** — списки відображаються як картки-папки прямо на стандартній сторінці закладок Lampa.
- **Хмарний бекап через GitHub Gist**
  - Зберігає у приватний Gist як власні списки, так і стандартні закладки Lampa.
  - Відновлення підтягує обидва файли назад, автоматично оновлюючи як списки так і закладки.
  - Потрібен персональний GitHub-токен (Settings → GitHub Token).
- **Імпорт з Trakt.tv** — завантажте ZIP-експорт зі свого акаунту Trakt.tv, і плагін:
  - прочитає його прямо в браузері (JSZip підвантажується з CDN лише за потреби);
  - створить окремі списки для кожного вашого списку Trakt, а також для Watchlist і Favorites.
- **Налаштування вбудовані в загальні Settings Lampa** — окрема секція «Налаштування списків» з полем токена, кнопками бекапу/відновлення та імпорту.

## Встановлення

1. У Lampa відкрийте **Налаштування → Розширення (плагіни)** і додайте посилання на файл https://lmpp.github.io/lmp/ll.js
3. Перезапустіть/оновіть Lampa — плагін ініціалізується автоматично після оновлення.

## Використання

### Додавання в список
Відкрийте картку фільму чи серіалу → кнопка «Закладки» → пункт «Списки» → оберіть існуючий список або створіть новий.

### Перегляд списків
Перейдіть на сторінку **Вибране**: над стандартними розділами з'явиться пункт «Мої списки» з лічильником. Відкрийте список, щоб побачити всі елементи, або видаліть список чи окремий елемент з нього.

### Резервне копіювання
1. Створіть [Personal Access Token](https://github.com/settings/tokens) на GitHub (достатньо прав `gist`).
2. Синхронізувати (Smart Merge): двостороннє об'єднання без втрати даних на обох сторонах (Локальне ⇄ Хмара).
3. Перезаписати в хмарі (Force Push): примусовий експорт — локальний стан на 100% затирає хмару (Локальне ➔ Хмара).
4. Відновити з хмари (Force Pull): примусовий імпорт — стан із хмари на 100% замінює локальні дані без злиття зі старими записами (Хмара ➔ Локальне).

### Імпорт з Trakt.tv
1. Експортуйте свої дані у [налаштуваннях Trakt.tv](https://trakt.tv/settings/data) (ZIP-архів).
2. Налаштування → «Налаштування списків» → «Імпорт з Trakt.tv» → оберіть завантажений ZIP.
3. Дочекайтеся завершення — списки, Watchlist і Favorites з'являться серед ваших локальних списків.
